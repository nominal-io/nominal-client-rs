# Guides

These guides go further than the [quickstart](../index.md), along the common path for each task.

- [Connect to Nominal](connect.md): create a client from a profile, or from an API key and URL.
- [Upload files and organize them](upload.md): upload files into datasets, and group them with assets and runs.
- [Stream data](stream.md): send points to a dataset as your program produces them.
