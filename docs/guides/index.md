# Guides

## Get started

- [Connect to Nominal](connect.md): create a client from a profile or an API key.
- [Cheat sheet](cheatsheet.md): one-line calls for common tasks.

## Organize data

- [Datasets](datasets.md): your test data, as channels such as `altitude`.
- [Assets](assets.md): the systems you test, and the data you add to each.
- [Runs](runs.md): the time span of each test, on one or more assets.
- [Channels](channels.md): find channels, and set their units and descriptions.

## Get data in

- [Upload files](upload.md): upload a file, and wait for Nominal to ingest it, whether natively or with an extractor.
- [Stream data](stream.md): send points to a dataset as your program produces them.
- [Drives and files](drives.md): find or create drives, and list and download their files.

## Review data

- [Workbooks](workbooks.md): create workbooks from templates for assets and runs.
- [Checklists](checklists.md): run checklists on streamed data, and read their live status.
- [Query data with SQL](sql.md): read your data back, and export large results to a file.

## Low-level functionality

- [Call the REST API directly](rest-api.md): create events and checklists, and execute a checklist on a run.

See [Examples](../examples/index.md) for complete programs.
